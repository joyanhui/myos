# raw OS 测试和验证方法

## 构建镜像

在仓库根目录执行：

```bash
mkdir -p tmp/raw-os-kvm
nix build --no-link --print-out-paths \
  .#nixosConfigurations.raw_os_core_img_creat.config.system.build.image \
  --option substituters https://cache.nixos.org \
  | tee tmp/raw-os-kvm/build-path.txt

path=$(tail -n 1 tmp/raw-os-kvm/build-path.txt)
cp --reflink=auto "$path/nixos.raw" tmp/raw-os-kvm/nixos.raw
chmod ugo+rw tmp/raw-os-kvm/nixos.raw
```

确认产物是 GPT raw 镜像：

```bash
qemu-img info tmp/raw-os-kvm/nixos.raw
```

## 构造外部宿主盘

测试不能把 `nixos.raw` 直接作为 QEMU 磁盘启动。先创建包含 ESP 和 NTFS 分区的宿主盘：

```bash
system=$(nix eval --raw .#nixosConfigurations.raw_os_core_img_creat.config.system.build.toplevel)

nix shell nixpkgs#grub2_efi nixpkgs#jq -c \
  machine/raw_os/docs_script/create-grubx64-efi.sh \
  "$system/boot.json" --serial \
  -o tmp/raw-os-kvm/grubx64.efi

qemu-img create -f raw tmp/raw-os-kvm/host-multidisk.raw 16G
nix shell nixpkgs#gptfdisk -c sgdisk --zap-all tmp/raw-os-kvm/host-multidisk.raw
nix shell nixpkgs#gptfdisk -c sgdisk \
  -n 1:2048:+128M -t 1:EF00 -c 1:ESP \
  -n 2:0:0 -t 2:0700 -c 2:HOSTNTFS \
  tmp/raw-os-kvm/host-multidisk.raw
qemu-img convert -f raw -O qcow2 \
  tmp/raw-os-kvm/host-multidisk.raw \
  tmp/raw-os-kvm/host-multidisk.qcow2
rm tmp/raw-os-kvm/host-multidisk.raw
```

通过 NBD 格式化并写入两个分区：

```bash
sudo $(nix build --no-link --print-out-paths nixpkgs#kmod | tail -n 1)/bin/modprobe nbd max_part=8
sudo qemu-nbd --format=qcow2 --connect=/dev/nbd0 tmp/raw-os-kvm/host-multidisk.qcow2
sudo mkfs.vfat -F 32 -n ESP /dev/nbd0p1
sudo mkfs.ntfs -F -L HOSTNTFS /dev/nbd0p2
sudo mkdir -p tmp/raw-os-kvm/mnt/{esp,ntfs}
sudo mount /dev/nbd0p1 tmp/raw-os-kvm/mnt/esp
sudo mount -t ntfs-3g /dev/nbd0p2 tmp/raw-os-kvm/mnt/ntfs
sudo mkdir -p tmp/raw-os-kvm/mnt/esp/EFI/BOOT tmp/raw-os-kvm/mnt/ntfs/OS-img
sudo cp tmp/raw-os-kvm/grubx64.efi \
  tmp/raw-os-kvm/mnt/esp/EFI/BOOT/BOOTX64.EFI
sudo cp tmp/raw-os-kvm/grubx64.efi \
  tmp/raw-os-kvm/mnt/esp/EFI/BOOT/grubx64.efi
sudo cp tmp/raw-os-kvm/nixos.raw \
  tmp/raw-os-kvm/mnt/ntfs/OS-img/nixos.raw
sudo sync
sudo umount tmp/raw-os-kvm/mnt/esp tmp/raw-os-kvm/mnt/ntfs
sudo qemu-nbd --disconnect /dev/nbd0
```

目录关系必须是：

```text
ESP/EFI/BOOT/BOOTX64.EFI
ESP/EFI/BOOT/grubx64.efi
HOSTNTFS/OS-img/nixos.raw
```

## KVM 闭环启动

使用临时 UEFI 变量文件启动宿主 qcow2。QEMU 只连接 `host-multidisk.qcow2`，不能连接 `nixos.raw`：

```bash
cp --reflink=auto kvm-config/firmware/OVMF_VARS.fd \
  tmp/raw-os-kvm/OVMF_VARS-external.fd

timeout --signal=TERM --kill-after=10s 120s \
  qemu-system-x86_64 \
    -name raw-os-external-grub-test \
    -enable-kvm \
    -machine q35,accel=kvm \
    -cpu host \
    -smp 2 \
    -m 2G \
    -drive if=pflash,format=raw,readonly=on,\
file=$PWD/kvm-config/firmware/OVMF.fd \
    -drive if=pflash,format=raw,\
file=$PWD/tmp/raw-os-kvm/OVMF_VARS-external.fd \
    -drive if=virtio,format=qcow2,\
file=$PWD/tmp/raw-os-kvm/host-multidisk.qcow2 \
    -display none \
    -chardev file,id=serial,\
path=$PWD/tmp/raw-os-kvm/qemu-external-grub-serial.log \
    -serial chardev:serial \
    -monitor none
```

## 验收条件

```bash
grep -E \
  'search|IMGLOOP:(start|found nixos.raw|losetup nixos.raw|done)|root present' \
  tmp/raw-os-kvm/qemu-external-grub-serial.log
```

必须确认：

- QEMU 使用 KVM 加速，并且只连接多分区宿主 qcow2。
- GRUB 从 ESP 启动，并在 NTFS 的 `OS-img/nixos.raw` 中找到镜像。
- initrd 输出 `IMGLOOP:found nixos.raw`、`IMGLOOP:losetup nixos.raw` 和 `IMGLOOP:done`。
- 日志不能出现 `root present directly on /dev/vda2`；该信息表示错误地把 `nixos.raw` 直接作为虚拟硬盘启动。
