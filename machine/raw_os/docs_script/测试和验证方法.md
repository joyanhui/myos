# Raw OS 测试和验证方法

## 验证目标

- raw 镜像可以直接从内部 `EFI/BOOT/BOOTX64.EFI` 启动。
- 内部菜单可以选择当前系统和 generation UKI。
- 内部菜单可以搜索并 chainload Windows Boot Manager。
- 外部固定 EFI 可以从 NTFS 加载 `OS-img/nixos.raw`。
- 替换 NTFS 中的 raw 镜像后，外部 EFI 仍可启动。
- `nixos-rebuild switch` 可以更新内部 EFI。
- 外部 ESP 不保存 generation UKI 和 raw 内部菜单。

## 产物

raw 镜像和内部 EFI 使用同一批配置构建：

```bash
mapfile -t outputs < <(
  nix build --no-link --print-out-paths \
    .#nixosConfigurations.raw_os_core_img_creat.config.system.build.image \
    .#nixosConfigurations.raw_os_core_img_creat.config.system.build.rawOsBootEfi \
    --option substituters https://cache.nixos.org
)
image_dir=${outputs[0]}
internal_efi=${outputs[1]}

cp --reflink=auto "$image_dir/nixos.raw" ./nixos.raw
file "$internal_efi"
qemu-img info ./nixos.raw
```

外部固定 EFI 单独构建：

```bash
REPO_DIR="$PWD" \
  machine/raw_os/docs_script/creat-rawOsExternalBootEfi.sh \
  -o /tmp/nixos-img.efi
external_efi=/tmp/nixos-img.efi
file "$external_efi"
```

检查：

```text
nixos.raw：GPT raw 镜像
internal_efi：x86-64 EFI executable
external_efi：x86-64 EFI executable
```

测试过程中临时启用串口控制台和自动登录。测试结束后必须删除临时配置并重新构建最终产物：

```nix
boot.kernelParams = [ "console=ttyS0" ];
systemd.services."serial-getty@ttyS0".enable = true;
```

## 内部启动

使用 raw 镜像作为 QEMU 磁盘：

```bash
cp --reflink=auto kvm-config/firmware/OVMF_VARS.fd /tmp/OVMF_VARS-internal.fd
qemu-system-x86_64 \
  -enable-kvm \
  -machine q35,accel=kvm \
  -cpu host \
  -smp 2 \
  -m 2G \
  -drive if=pflash,format=raw,readonly=on,file=kvm-config/firmware/OVMF.fd \
  -drive if=pflash,format=raw,file=/tmp/OVMF_VARS-internal.fd \
  -drive if=virtio,format=raw,file=./nixos.raw \
  -display none \
  -serial tcp:127.0.0.1:45581,server,nowait \
  -monitor none
```

应看到：

```text
IMGLOOP:start
IMGLOOP:done
```

内部验收重点：

- UEFI 加载 `EFI/BOOT/BOOTX64.EFI`；
- GRUB 加载 `EFI/NixOS/raw-os/grub.cfg`；
- 菜单包含当前系统、generation 和 Windows Boot Manager；
- `nixos-current.efi` 存在；
- generation UKI 数量不超过 10 个；
- `nixos-rebuild switch` 输出内部 EFI 更新结果。

## 外部测试盘

外部测试盘包含 1 GiB FAT32 ESP 和 NTFS 分区：

```bash
set -euo pipefail
work=/tmp/raw-os-kvm
rm -rf "$work"
mkdir -p "$work/mnt/esp" "$work/mnt/ntfs"
qemu-img create -f raw "$work/host.raw" 16G
sgdisk --zap-all "$work/host.raw"
sgdisk \
  -n 1:2048:+1G -t 1:EF00 -c 1:ESP \
  -n 2:0:0 -t 2:0700 -c 2:HOSTNTFS \
  "$work/host.raw"
qemu-img convert -f raw -O qcow2 "$work/host.raw" "$work/host.qcow2"
rm "$work/host.raw"

sudo modprobe nbd max_part=8
sudo qemu-nbd --format=qcow2 --connect=/dev/nbd0 "$work/host.qcow2"
for i in $(seq 1 30); do
  [ -b /dev/nbd0p1 ] && [ -b /dev/nbd0p2 ] && break
  sleep 1
done
sudo mkfs.vfat -F 32 -n ESP /dev/nbd0p1
sudo mkfs.ntfs -F -L HOSTNTFS /dev/nbd0p2
sudo mount /dev/nbd0p1 "$work/mnt/esp"
sudo mount -t ntfs-3g /dev/nbd0p2 "$work/mnt/ntfs"
sudo mkdir -p "$work/mnt/esp/EFI/NixOS" "$work/mnt/esp/EFI/BOOT" "$work/mnt/ntfs/OS-img"
sudo cp --sparse=never "$external_efi" \
  "$work/mnt/esp/EFI/NixOS/nixos-img.efi"
sudo cp --sparse=never "$external_efi" \
  "$work/mnt/esp/EFI/BOOT/BOOTX64.EFI"
sudo cp --sparse=never ./nixos.raw \
  "$work/mnt/ntfs/OS-img/nixos.raw"
sudo sync
sudo umount "$work/mnt/esp" "$work/mnt/ntfs"
sudo qemu-nbd --disconnect /dev/nbd0
```

第一次启动只使用 `EFI/BOOT/BOOTX64.EFI` 注册外部 UEFI 启动项。注册完成并通过 `BootNext` 启动自定义路径后，删除外部 ESP 的 fallback：

```bash
sudo qemu-nbd --format=qcow2 --connect=/dev/nbd0 "$work/host.qcow2"
sudo mount /dev/nbd0p1 "$work/mnt/esp"
sudo rm -f "$work/mnt/esp/EFI/BOOT/BOOTX64.EFI"
sudo sync
sudo umount "$work/mnt/esp"
sudo qemu-nbd --disconnect /dev/nbd0
```

第二次启动必须满足：

- UEFI 从自定义 EFI 路径启动；
- 外部固定 EFI 找到 NTFS 中的 `OS-img/nixos.raw`；
- 出现 `IMGLOOP:found nixos.raw` 和 `IMGLOOP:done`；
- 外部 ESP 不包含 generation UKI；
- 删除 fallback 后仍能启动。

## 替换 raw 验证

保存外部 EFI hash：

```bash
sha256sum "$external_efi"
```

用另一份 raw 替换 NTFS 中的文件：

```bash
sudo qemu-nbd --format=qcow2 --connect=/dev/nbd0 "$work/host.qcow2"
sudo mount -t ntfs-3g /dev/nbd0p2 "$work/mnt/ntfs"
sudo cp --sparse=never ./replacement.raw \
  "$work/mnt/ntfs/OS-img/nixos.raw"
sudo sync
sudo umount "$work/mnt/ntfs"
sudo qemu-nbd --disconnect /dev/nbd0
```

再次启动并确认：

- 外部 EFI hash 不变；
- 新 raw 镜像可以启动；
- `IMGLOOP:done` 出现。

## 清理

测试结束后确认没有 QEMU、NBD 和挂载残留：

```bash
sudo umount -l "$work/mnt/esp" "$work/mnt/ntfs" 2>/dev/null || true
sudo qemu-nbd --disconnect /dev/nbd0 2>/dev/null || true
```

不要使用真实磁盘或真实 NVRAM 进行 QEMU 测试。
