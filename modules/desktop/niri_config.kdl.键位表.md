# niri 快捷键

## 基础操作

| 快捷键 | 功能 |
|---|---|
| `Alt+Shift+Slash` | 显示快捷键帮助 |
| `Alt+Return` | 启动 Ghostty |
| `Alt+Ctrl+Shift+Return` | 启动 Kitty |
| `Alt+Shift+R` | 应用启动器 |
| `Alt+Ctrl+Shift+R` | 重启 fcitx5 |
| `Alt+Shift+Q` | 关闭窗口 |
| `Alt+Ctrl+Shift+E` | 退出 niri |
| `Alt+Shift+A` | 窗口切换 |

## 焦点和窗口移动

| 快捷键 | 功能 |
|---|---|
| `Alt+Shift+Left` | 聚焦左侧列 |
| `Alt+Shift+Right` | 聚焦右侧列 |
| `Alt+Shift+Up` | 聚焦上方窗口 |
| `Alt+Shift+Down` | 聚焦下方窗口 |
| `Alt+Ctrl+Shift+Left` | 向左移动列 |
| `Alt+Ctrl+Shift+Right` | 向右移动列 |
| `Alt+Ctrl+Shift+Up` | 向上移动窗口 |
| `Alt+Ctrl+Shift+Down` | 向下移动窗口 |

## 窗口布局

| 快捷键 | 功能 |
|---|---|
| `Alt+Shift+F` | 最大化列 |
| `Alt+Ctrl+Shift+F` | 全屏窗口 |
| `Alt+Shift+M` | 最大化窗口到边缘 |
| `Alt+Shift+V` | 切换窗口浮动状态 |
| `Alt+Ctrl+Shift+V` | 在浮动窗口和平铺窗口之间切换焦点 |
| `Alt+Shift+W` | 切换列的 Tabbed 显示 |
| `Alt+Ctrl+Shift+W` | 切换预设列宽 |
| `Alt+Shift+H` | 重置窗口高度 |
| `Alt+Shift+C` | 居中列 |
| `Alt+Minus` | 减小列宽 |
| `Alt+Equal` | 增大列宽 |
| `Alt+Shift+Minus` | 减小窗口高度 |
| `Alt+Shift+Equal` | 增大窗口高度 |
| `Alt+Comma` | 将窗口合并到列 |
| `Alt+Period` | 将窗口移出列 |
| `Alt+BracketLeft` | 合并或移出左侧窗口 |
| `Alt+BracketRight` | 合并或移出右侧窗口 |

## 其他操作

| 快捷键 | 功能 |
|---|---|
| `Alt+Shift+O` | 切换 Overview |
| `Alt+Shift+S` | 截图界面 |
| `Alt+Shift+Print` | 截取当前屏幕 |
| `Alt+Ctrl+Shift+Print` | 截取当前窗口 |
| `Alt+Shift+Escape` | 切换键盘快捷键拦截 |
| `Alt+Ctrl+Shift+P` | 关闭显示器 |
