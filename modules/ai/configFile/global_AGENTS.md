# Global Default Instructions

## 特殊项目
- Use `gh` command to view GitHub Actions records.
- 使用bunx wangler 自动处理和Cloudflare worker的交互，但是部分项目明确是使用GitHub触发Cloudflare worker构建的 就不要手动执行wangler命令。

## 语言和注释
- Always communicate in Chinese (中文).
- Use English for: git commit messages, function names, constants, comments, logs, error messages — unless the project has special requirements.
## 文档创建规范
- 除非明确要求，新建文档不得使用emoji 不得使用 **xx**
- 多使用`-`列表,避免太多空行，避免废话。
- 除非明确要求，否则不要在文档中写大量的示例代码和约定俗成的文案。
